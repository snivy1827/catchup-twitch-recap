# Demo video storyboard — target 165 seconds

English narration/captions. Record actual live mode after validation; do not substitute offline fixtures for Twitch operation.

| Time | Screen | Narration |
| --- | --- | --- |
| 0–15s | Game stream and a viewer arriving | “Joining halfway through a stream should not mean missing the story.” |
| 15–35s | CatchUp control page, OBS game source, Start | “The broadcaster enables CatchUp. It samples the game screen and keeps compact visual progress notes.” |
| 35–65s | Pre-collected real event cards, timestamps and current goal | “Each update includes evidence from the broadcast. Uncertain details remain uncertain. No need to replay hours of video for each viewer.” |
| 65–95s | Actual Twitch viewer sends !recap; visible response | “A single command provides the context. Everyone uses the same cached summary.” |
| 95–120s | Public HTTPS recap page | “Viewers browse illustrated cards at their own pace. This prototype publishes timestamped snapshots manually.” |
| 120–135s | Second command and cost panel | “Cooldowns prevent spam, and a session budget limits further analysis.” |
| 135–155s | This Codex development session, generated modules and test results | “Built with Codex: product spec, OBS capture, vision analysis, Twitch integration and reproducible offline tests.” |
| 155–165s | Final viewer page | “CatchUp. Late to the stream. Right in the story.” |

Prepare events before recording, clearly disclose any time cuts. Keep secrets and private information offscreen. Disable unlicensed music. Replace claims if a feature has not actually been validated. The official video must be public on YouTube; an exported ZIP is not a video submission.
